# COMO PEGAR O CÓDIGO NO ADCASH
# ================================

## PASSO A PASSO COM IMAGENS

### 1. FAÇA LOGIN NO ADCASH
   Acesse: https://adcash.com/publishers/login
   - Email: (seu email)
   - Password: (sua senha)
   - Clique em "Login"

### 2. VÁ PARA O DASHBOARD
   Após login, você verá o painel principal
   Procure o menu lateral esquerdo

### 3. ADICIONE SEU SITE (se ainda não adicionou)
   
   a) Clique em "Sites" no menu lateral
   b) Clique em "Add New Website" ou "+"
   c) Preencha:
      - Website URL: https://tech-tips.byethost4.com
      - Category/Vertical: News ou Technology
      - Traffic Type: Display
   d) Clique em "Add" ou "Save"
   e) Aguarde aprovação (geralmente instantâneo)

### 4. OBTER O CÓDIGO DO ANÚNCIO

   a) Clique em "Sites" no menu lateral
   b) Clique no nome do seu site
   c) Procure um botão que diz:
      - "Get Code" OU
      - "Ad Tags" OU
      - "Tags" OU
      - "Integration"
   
   d) Clique nesse botão

### 5. ESCOLHA O TIPO DE ANÚNCIO

   Você verá opções como:
   - Banner (728x90, 300x250, etc.)
   - Popunder
   - Interstitial
   - Push Notification
   
   ESCOLHA: "Banner" ou "Display"

### 6. COPIE O CÓDIGO

   Você verá algo assim:

   <script async data-cfasync="false" 
     src="https://cdn.ad-cash.com/adcash.js">
   </script>

   COPIE TODO ESSE CÓDIGO!
   
   (Selecione tudo e Ctrl+C)

### 7. PRONTO!
   Agora você tem o código para colar no Ad Inserter

## ONDE ESTÁ CADA COISA NO ADCASH

Menu lateral (esquerda):
├── Dashboard (visão geral)
├── Sites (gerenciar sites)
│   └── [Seu site]
│       └── Get Code / Ad Tags ← AQUI!
├── Reports (relatórios)
├── Payments (pagamentos)
└── Settings (configurações)

## DICAS

### Se não encontra "Get Code":
- Procure por "Tags" ou "Ad Tags"
- Ou "Integration" ou "Setup"
- Pode estar em "Sites" → [Nome do site]

### Se pede para criar "Tag":
- Clique em "Create Tag" ou "New Tag"
- Escolha o formato (Banner)
- O código será gerado automaticamente

### Código vs Tag:
- Código = a tag HTML que você cola no site
- Tag = a configuração do anúncio no AdCash
- Você precisa do CÓDIGO (a tag HTML)

## FORMATOS DE ANÚNCIO RECOMENDADOS

Para cada posição no Ad Inserter:

BLOCO 1 (Header): Banner 728x90
BLOCO 2 (Sidebar): Rectangle 300x250
BLOCO 3 (In-Content): Banner 728x90
BLOCO 4 (Footer): Banner 728x90

Cada formato tem um código diferente.
Você pode usar o mesmo código em todos os blocos.
