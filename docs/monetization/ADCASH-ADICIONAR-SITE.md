# COMO ADICIONAR SITE NO ADCASH E PEGAR O CÓDIGO
# ================================================

## O QUE ESTÁ ACONTECENDO:

O site precisa ser ADICIONADO e APROVADO antes
de gerar o código de anúncio.

---

## PASSO A PASSO:

### PASSO 1: ADICIONAR O SITE

Na página que você está (Sites), procure:

  ┌─────────────────────────────────────┐
  │  [Add New Website]  ou  [ + Add ]  │
  └─────────────────────────────────────┘

CLIQUE NELE!

---

### PASSO 2: PREENCHER OS DADOS

Você verá um formulário. Preencha:

  Website URL: https://tech-tips.byethost4.com
  
  Category/Vertical: News (Notícias)
  
  Traffic Type: Display
  
  Adult Content: NO (Não)

Clique em "Add" ou "Save" ou "Submit"

---

### PASSO 3: AGUARDAR APROVAÇÃO

Após adicionar, o site entra em análise.

Status que você pode ver:
- "Pending" = Aguardando aprovação
- "Approved" = Aprovado! Pode gerar código
- "Rejected" = Rejeitado (verificar dados)

---

### PASSO 4: QUANDO APROVADO, GERAR O CÓDIGO

Após aprovação, o botão "Get Code" aparece.

Clique em "Get Code" → Escolha "Banner" → Copie o código

---

## SE O SITE JÁ ESTÁ NA LISTA MAS SEM STATUS:

Isso significa que está PENDENTE (aguardando).

Neste caso:
1. Aguarde some horas (até 24h)
2. Atualize a página (F5)
3. O status deve aparecer

---

## SE NÃO CONSEGUE ADICIONAR O SITE:

Verifique:
1. A URL está correta? (https://...)
2. A categoria está selecionada?
3. Tem algum erro no formulário?

---

## ENQUANTO AGUARDADO, VAMOS USAR UM CÓDIGO TEMPORÁRIO:

Enquanto o AdCash aprova o site, você pode
usar um código de teste para verificar se
o Ad Inserter está funcionando:

Copie este código e cole no Ad Inserter:

<!-- Código de Teste -->
<div style="background:#e8f4f8; padding:20px; text-align:center; border:2px dashed #0073aa; margin:10px 0;">
<strong>广告区域 - Ad Placeholder</strong><br>
<small>Este é um espaço para anúncio</small>
</div>

Este código mostra um quadrado azul claro.
Se aparecer no site, o Ad Inserter está funcionando!

---

## RESUMO:

1. Clique em "Add New Website"
2. Preencha: https://tech-tips.byethost4.com
3. Category: News
4. Clique em "Add"
5. Aguarde aprovação (horas)
6. Depois "Get Code" aparece
