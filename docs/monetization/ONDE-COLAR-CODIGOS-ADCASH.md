# GUIA: Onde Colar os Códigos do AdCash
# ================================

## PASSO 1: CRIAR CONTA NO ADCASH

1. Acesse: https://adcash.com/publishers/signup
2. Preencha:
   - Email: (seu email real)
   - Password: (senha forte)
   - Type: Publisher
   - Currency: USD
3. Clique em "Register"
4. Valide o email (checar caixa de entrada)

## PASSO 2: ADICIONAR SEU SITE NO ADCASH

1. Após login, vá em "Sites" ou "Add Website"
2. Clique em "Add New"
3. Preencha:
   - Website URL: https://tech-tips.byethost4.com
   - Vertical: News ou Technology
   - Traffic Type: Display
   - Adult Content: NÃO (desmarcado)
4. Clique em "Add" ou "Save"
5. Aguarde aprovação (geralmente instantâneo)

## PASSO 3: OBTER O CÓDIGO DE RASTREAMENTO

1. Vá em "Sites" → Seu site → "Get Code" ou "Ad Tags"
2. Você verá um código assim:

<script async data-cfasync="false" src="https://cdn.ad-cash.com/adcash.js"></script>

3. COPIE esse código

## PASSO 4: COLAR NO AD INSERTER (WORDPRESS)

1. Acesse: https://tech-tips.byethost4.com/wp-admin/
2. Vá em: Settings → Ad Inserter
3. Você verá os 4 blocos configurados

### BLOCO 1 (Header Banner):
1. Clique em "Block 1"
2. Procure o campo "Block code" ou "Code"
3. APAGUE o código que está lá
4. COLE o código do AdCash
5. Clique em "Save"

### BLOCO 2 (Sidebar Rectangle):
1. Clique em "Block 2"
2. APAGUE o código antigo
3. COLE o código do AdCash
4. Clique em "Save"

### BLOCO 3 (In-Content Ad):
1. Clique em "Block 3"
2. APAGUE o código antigo
3. COLE o código do AdCash
4. Clique em "Save"

### BLOCO 4 (Footer Banner):
1. Clique em "Block 4"
2. APAGUE o código antigo
3. COLE o código do AdCash
4. Clique em "Save"

## PASSO 5: VERIFICAR SE FUNCIONOU

1. Acesse seu site: https://tech-tips.byethost4.com
2. Procure os anúncios:
   - No TOPO (Header)
   - Na LATERAL (Sidebar)
   - No MEIO do conteúdo
   - No RODAPÉ (Footer)

## DICAS IMPORTANTES

### Onde encontrar o código no AdCash:
- Dashboard → Sites → [Seu site] → Get Code
- OU: Tags → Create Tag

### Como colar no AdInserter:
- O campo de código fica em cada bloco
- Geralmente é um textarea grande
- Cole o código inteiro lá

### Se não aparecer:
1. Limpe o cache (Ctrl+F5)
2. Verifique se o código está correto
3. Teste em modo anônimo (Ctrl+Shift+N)

### Anúncios diferentes por posição:
Você pode usar formatos diferentes:
- Header: Banner 728x90
- Sidebar: Rectangle 300x250
- In-Content: Banner 728x90 ou 336x280
- Footer: Banner 728x90

Cada formato tem código diferente no AdCash.

## RESUMO RÁPIDO

1. Criar conta AdCash → adcash.com
2. Adicionar site no AdCash
3. Copiar código de rastreamento
4. Colar no AdInserter:
   - Block 1 → Código do AdCash
   - Block 2 → Código do AdCash
   - Block 3 → Código do AdCash
   - Block 4 → Código do AdCash
5. Salvar
6. Verificar no site
